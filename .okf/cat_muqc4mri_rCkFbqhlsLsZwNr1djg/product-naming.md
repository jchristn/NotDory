Use "NotDory" in prose and C# (namespaces NotDory.*), lowercase "notdory" in config keys, Docker image names (jchristn77/notdory-*), the MCP server key, env vars (NOTDORY_*), and file names. The logo is assets/notdory.png (served from a new path to defeat stale caches, commit 6953d2d).
